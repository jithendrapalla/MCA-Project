# Modified AES Algorithm with Chaotic Mapping SubBytes & Dynamic ShiftRows

## Overview

This project presents an enhanced version of the Advanced Encryption Standard (AES) algorithm by introducing two security improvements:

1. **Chaotic Mapping-Based SubBytes**
2. **Dynamic ShiftRows Transformation**

The goal of this modification is to improve encryption strength and increase resistance against cryptographic attacks while maintaining the core structure of the standard AES algorithm.

## Project Title

**Modified AES Algorithm with Chaotic Mapping SubBytes & Dynamic ShiftRows**

## Objective

The main objective of this project is to enhance the security of the traditional AES encryption algorithm by replacing static operations with dynamic and chaotic transformations. These modifications increase randomness and make the encryption process more difficult to predict.

## Features

* Implementation of Standard AES Encryption
* Chaotic Mapping-Based SubBytes Transformation
* Dynamic ShiftRows Operation
* Encryption and Decryption Support
* Performance Comparison with Standard AES
* Security Analysis and Result Evaluation
* Educational Demonstration of Advanced Cryptographic Concepts

## Project Structure

* **Source Code** – Implementation of Standard AES and Modified AES algorithms.
* **Record Book** – Complete project documentation submitted to the college.

## Technologies Used

* Python
* Cryptography Concepts
* AES Encryption Algorithm
* Chaotic Mapping Techniques

## Working Process

1. Plaintext is provided as input.
2. AES key generation is performed.
3. Chaotic Mapping is applied during the SubBytes stage.
4. Dynamic ShiftRows transformation is executed.
5. Remaining AES rounds are processed.
6. Ciphertext is generated.
7. Decryption verifies data integrity and correctness.

## Results

The modified AES algorithm demonstrates increased randomness and enhanced security characteristics compared to the standard AES implementation. Experimental results show the effectiveness of chaotic mapping and dynamic row shifting in strengthening the encryption process.
